## 🎯 Sobre o Minicurso

Bem-vindo ao repositório oficial do minicurso **"Construção de Websites com WordPress"**, realizado durante a **SEMAC XI** na Universidade Federal de Sergipe!

Aqui você encontrará todos os materiais necessários para acompanhar e replicar o projeto desenvolvido durante o curso.

### ✨ O que você vai aprender

- 🎨 Criação de landing pages profissionais
- 🛠️ Utilização do WordPress e suas funcionalidades
- 🎯 Domínio do plugin Elementor para design visual
- 📱 Desenvolvimento responsivo e moderno
